# PORA · พอร่า

**เห็นเงินเหลือ ก่อนใช้จริง** — เว็บภาษาไทยสำหรับดูเงินเหลือหลังกันบิลและเงินที่อยากเก็บ จนถึงเงินเข้าครั้งหน้า

## เปิดระหว่างพัฒนา

ใช้ Node.js 24 LTS และ npm (ตรวจแล้วด้วย Node 24.15.0):

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด URL ที่ Vite แสดง สำหรับ PowerShell ใช้ `npm.cmd` เพื่อไม่ติดข้อจำกัดการรัน `npm.ps1` บนเครื่องนี้ ระบบอื่นใช้ `npm` ได้

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

`test` ตรวจสูตรและ storage, `build` ตรวจ TypeScript และสร้าง `dist/`, `preview` เปิดผล production สำหรับตรวจ PWA การตรวจออฟไลน์ต้องรอข้อความ “พร้อมเปิดใช้ออฟไลน์” ก่อน แล้วปิดเครือข่ายและลองรีโหลด

## วิธีใช้

1. ลองข้อมูลตัวอย่าง หรือเริ่มด้วยยอดเงินจริง วันเงินเข้ารอบหน้า และเงินกันเพิ่มเติม
2. เพิ่มบิลค้าง จากนั้นบันทึกรายรับ/รายจ่ายเมื่อได้รับหรือจ่ายเงินจริง
3. กด “จ่ายแล้ว” ที่บิลเพื่อสร้างรายจ่ายที่เชื่อมกัน ย้อนการจ่ายหรือแก้รายการได้
4. ใช้ “ปรับยอดให้ตรงกับเงินจริง” เมื่อตัวเลขไม่ตรง ระบบเพิ่มเฉพาะผลต่าง
5. เมื่อถึงวันเงินเข้า บันทึกรายรับจริงและตั้งวันเงินเข้ารอบใหม่ ไม่มีการเติมรายรับอัตโนมัติ

เงินทั้งหมดเก็บเป็นสตางค์ จำนวนวันใช้ Asia/Bangkok บิลตรงวันเงินเข้าหรือหลังจากนั้นไม่ถูกกันในรอบปัจจุบัน โหมดตัวอย่างแยกจากข้อมูลส่วนตัว

## สำรองและย้ายข้อมูล

ตั้งค่า → ส่งออกข้อมูล จะดาวน์โหลด `pora-personal-YYYY-MM-DD.json` หรือไฟล์โหมดตัวอย่าง เก็บไว้ในที่ปลอดภัย นำเข้าผ่านหน้าตั้งค่า ระบบตรวจไฟล์และถามก่อนแทนที่ข้อมูล รองรับไฟล์สำรองชื่อแอปเดิม `leua-use` ด้วย

ข้อมูลอยู่ใน `localStorage` ของเบราว์เซอร์นี้ ไม่ส่งขึ้นเซิร์ฟเวอร์ ไม่ซิงก์ข้ามเครื่อง และไม่มีระบบล็อกบัญชี สำรองก่อนล้างเว็บไซต์ เปลี่ยนเครื่อง เบราว์เซอร์ พอร์ต หรือโดเมน เพราะแต่ละ origin มีพื้นที่เก็บข้อมูลแยกกัน

## PWA

Safari บน iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม; Chrome บน Android: เมนู → เพิ่มลงหน้าจอหลัก/ติดตั้งแอป ความสามารถขึ้นกับอุปกรณ์ สำรองก่อนติดตั้ง เนื่องจากบางอุปกรณ์อาจมี storage แยกจากแท็บเดิม

เมื่อมีเวอร์ชันใหม่ เลือก “อัปเดตแอป” หรือ “ไว้ภายหลัง” บันทึกหรือปิดฟอร์มก่อนอัปเดต

## เผยแพร่

ปลายทางตามแผนคือ Cloudflare Pages แบบ static เท่านั้น สร้าง production build แล้วอัปโหลด **ไฟล์ภายใน `dist/`** โดยให้ `index.html` อยู่ที่ราก ใช้ชื่อโปรเจกต์ `pora-demo` หากว่าง และรักษาที่อยู่เดิมสำหรับผู้ทดลอง ไม่อัปโหลด source, `node_modules` หรือข้อมูลสำรองส่วนตัว ไม่เพิ่มบริการเสียเงิน ฐานข้อมูล หรือ Functions

เว็บทดลอง: **https://pora-demo.pages.dev** — เผยแพร่ 9 ตุลาคม 2569 (Asia/Bangkok) ตรวจ HTTPS, refresh, manifest, offline และการบันทึกบน origin จริงด้วย Chromium แล้ว ยังรอการตรวจบนมือถือจริง

อัปเดตเว็บเดิมหลังตรวจงานและ build ผ่าน:

```powershell
npx.cmd wrangler pages deploy dist --project-name pora-demo --branch main
```

ใช้โปรเจกต์นี้ต่อเพื่อรักษา origin เดิม ไม่ต้องสร้างใหม่ การ push Git อย่างเดียวไม่เผยแพร่เว็บ เพราะโปรเจกต์ใช้ Direct Upload

- `src/PwaStatus.tsx`, `vite.config.ts`, `public/`: PWA และไอคอน
